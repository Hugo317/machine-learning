# Machine Learning

Exercises working through practical machine learning, organised by day. Each notebook keeps its
outputs, so the work is visible without re-running.

| Day | Topic | Covers |
|-----|-------|--------|
| 1 | Classification & regression | churn classification, logistic regression, regression, model comparison |
| 2 | Model selection | cross-validation, grid search; labs on hotel classification and insurance regression |
| 3 | Data leakage | a tainted-data / restart demo |
| 4 | Deep learning — CNNs | image classification with a convolutional network |
| 5 | Deep learning — RNNs | sequence modelling with a recurrent network |

Python with `scikit-learn`, `pandas`, `numpy` and `matplotlib`; TensorFlow/Keras for the
deep-learning days.
